بسته‌ی لوگوی بیوتی‌ولت — «الماسِ تیک»
ایده: الماس = ارزش و پول کاربر. تیک = «قبل از خرید چک شد»؛ ما طرف خریداریم.

کدام فایل برای کجا:
- png/instagram-profile-1080.png  → عکس پروفایل اینستاگرام (برای برش دایره‌ای آماده است)
- png/app-icon-1024.png            → آیکن اپ و کافه‌بازار/مایکت
- png/logo-full-white.png          → لوگوی کامل روی سفید (پست، ارائه، شتاب‌دهنده)
- png/logo-full-dark.png           → لوگوی کامل روی سرمه‌ای
- png/logo-full-transparent.png    → لوگوی کامل بدون پس‌زمینه
- png/logo-horizontal-transparent.png → لوگوی افقی (هدر سایت، امضای ایمیل)
- png/icon-*-transparent-1024.png  → فقط الماس، بدون پس‌زمینه (اصلی، صورتی، خطی، قطره)
- svg/*.svg                        → نسخه‌ی برداری برای چاپ و طراح (هر اندازه‌ای بدون افت کیفیت)
- svg/beautywallet-icon-small.svg  → نسخه‌ی ساده برای اندازه‌ی خیلی کوچک (زیر ۴۸ پیکسل)
