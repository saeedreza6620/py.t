**<span dir="rtl">فصل سوم</span>**

**<span dir="rtl">روش تحقیق: مدل ریاضی، هندسه، مش‌بندی و حل عددی</span>**

**<span dir="rtl">۳‏-‏۱ مقدمه</span>**

<span dir="rtl">در این فصل روش مدل‌سازی رهایش دارو از میکروسفر ژلاتینی کراس‌لینک‌شده</span>[^1] <span dir="rtl">با گلوتارآلدئید</span>[^2] <span dir="rtl">گام‌به‌گام شرح داده می‌شود. هدف این است که هر عددی که در فصل نتایج می‌آید قابل بازتولید باشد: معادله حاکم چیست، هندسه و مش چگونه ساخته شده، حل عددی با چه دقتی انجام شده، داده تجربی از کجا و چگونه استخراج شده و مدل با چه معیاری با داده مقایسه می‌شود. همه محاسبه‌های این فصل واقعاً اجرا شده‌اند و جدول‌ها خروجی مستقیم همان اجراها هستند.</span>

<span dir="rtl">اصل راهنمای این پایان‌نامه این است که هیچ پارامتری با برازش روی منحنی رهایش به دست نیاید. ضریب نفوذ از رابطه‌های منتشرشده محاسبه می‌شود و اندازه ذره، بارگذاری دارو و شرایط آزمون از همان مقاله‌ای گرفته می‌شود که داده رهایش را گزارش کرده است. به همین دلیل، دقت حل عددی باید جدا از دقت مدل سنجیده شود؛ بخش‌های ۳‏-‏۷ تا ۳‏-‏۹ برای همین کار نوشته شده‌اند.</span>

**<span dir="rtl">۳‏-‏۲ تعریف مسئله و فرض‌ها</span>**

<span dir="rtl">سامانه مورد بررسی یک میکروسفر ژلاتینی است که دارو در آن پخش شده و در محیط آبی (بافر فسفات،</span> ‎pH ۷٫۴‎ <span dir="rtl">و دمای</span> ‎۳۷ °C‎<span dir="rtl">) قرار می‌گیرد. کمیتی که آزمایش اندازه می‌گیرد کسر تجمعی داروی آزادشده برحسب زمان است. مدل پایه بر این فرض‌ها بنا شده است:</span>

<span dir="rtl">• میکروسفر کره کامل است و همه ذره‌ها شعاع یکسان</span> ‎R‎ <span dir="rtl">دارند (شعاع میانگین گزارش‌شده در مقاله). اثر توزیع اندازه در فصل نتایج با تحلیل حساسیت بررسی می‌شود.</span>

<span dir="rtl">• تقارن کروی برقرار است؛ غلظت فقط تابع شعاع</span> ‎r‎ <span dir="rtl">و زمان</span> ‎t‎ <span dir="rtl">است.</span>

<span dir="rtl">• دارو در لحظه صفر یکنواخت در ذره پخش است (دارو پیش از امولسیون در محلول ژلاتین حل شده است).</span>

<span dir="rtl">• محیط بیرون مخزن کامل</span>[^3] <span dir="rtl">است؛ غلظت دارو روی سطح ذره صفر می‌ماند. در آزمون مرجع</span> ‎۲۰ mg‎ <span dir="rtl">دارو در</span> ‎۱۰۰ ml‎ <span dir="rtl">بافر آزاد می‌شود.</span>

<span dir="rtl">• در مدل پایه شعاع ذره و ضریب نفوذ با زمان ثابت‌اند. تورم، اتصال دارو به ژلاتین و تخریب شبکه در مدل توسعه‌یافته (بخش ۳‏-‏۱۲) وارد می‌شوند.</span>

<span dir="rtl">• انتقال جرم در لایه مرزی بیرون ذره کندکننده نیست (محیط هم‌زده می‌شود).</span>

**<span dir="rtl">۳‏-‏۳ معادله‌های حاکم</span>**

**<span dir="rtl">۳‏-‏۳‏-‏۱ مدل پایه: قانون دوم فیک در کره</span>**

<span dir="rtl">موازنه جرم داروی آزاد در یک پوسته کروی، قانون دوم فیک</span>[^4] <span dir="rtl">را در مختصات کروی می‌دهد \[</span>‎۱‎<span dir="rtl">،</span> ‎۲‎<span dir="rtl">\]:</span>

|                                                                                                                                      |                                         |
|--------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------|
| $\frac{\partial C}{\partial t}\  = \ \frac{1}{r^{2}}\frac{\partial}{\partial r}\left( D\ r^{2}\frac{\partial C}{\partial r} \right)$ | **<span dir="rtl">معادله (۳‏-‏۱)</span>** |

<span dir="rtl">که</span> ‎C‎ <span dir="rtl">غلظت دارو (</span>‎mg/cm³‎<span dir="rtl">)،</span> ‎r‎ <span dir="rtl">فاصله از مرکز (</span>‎cm‎<span dir="rtl">)،</span> ‎t‎ <span dir="rtl">زمان (</span>‎s‎<span dir="rtl">) و</span> ‎D‎ <span dir="rtl">ضریب نفوذ دارو در ژل متورم (</span>‎cm²/s‎<span dir="rtl">) است. شرط اولیه و شرط‌های مرزی چنین‌اند:</span>

|                                                      |                                         |
|------------------------------------------------------|-----------------------------------------|
| $C(r,\ 0)\  = \ C_{0},\ \ \ 0\  \leq \ r\  \leq \ R$ | **<span dir="rtl">معادله (۳‏-‏۲)</span>** |

|                                                                |                                         |
|----------------------------------------------------------------|-----------------------------------------|
| $\frac{\partial C}{\partial r}\  = \ 0\ \ \ at\ \ \ r\  = \ 0$ | **<span dir="rtl">معادله (۳‏-‏۳)</span>** |

|                    |                                         |
|--------------------|-----------------------------------------|
| $C(R,\ t)\  = \ 0$ | **<span dir="rtl">معادله (۳‏-‏۴)</span>** |

<span dir="rtl">معادله (۳‏-‏۳) شرط تقارن در مرکز و معادله (۳‏-‏۴) شرط مخزن کامل روی سطح است. کسر تجمعی رهایش از موجودی باقی‌مانده در ذره به دست می‌آید:</span>

|                                                                                                    |                                         |
|----------------------------------------------------------------------------------------------------|-----------------------------------------|
| $F(t)\  = \ \frac{M_{t}}{M_{\infty}}\  = \ 1\  - \ \frac{3}{R^{3}C_{0}}\int_{0}^{R}{C\ r^{2}\ dr}$ | **<span dir="rtl">معادله (۳‏-‏۵)</span>** |

**<span dir="rtl">۳‏-‏۳‏-‏۲ شکل بی‌بعد</span>**

<span dir="rtl">با تعریف</span> ‎x = r/R‎<span dir="rtl">،</span> ‎c = C/C<sub>۰‎</sub> <span dir="rtl">و زمان بی‌بعد</span> ‎τ = D t / R²‎ <span dir="rtl">(عدد فوریه جرمی</span>[^5]<span dir="rtl">)، معادله به شکل زیر درمی‌آید که هیچ پارامتری ندارد:</span>

|                                                                                                                                                                                  |                                         |
|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------|
| $\frac{\partial c}{\partial\tau}\  = \ \frac{1}{x^{2}}\frac{\partial}{\partial x}\left( x^{2}\frac{\partial c}{\partial x} \right),\ \ \ c(x,0)\  = \ 1,\ \ \ c(1,\tau)\  = \ 0$ | **<span dir="rtl">معادله (۳‏-‏۶)</span>** |

<span dir="rtl">مزیت این شکل آن است که مطالعه مش و گام زمانی یک بار انجام می‌شود و برای هر دارو و هر اندازه ذره معتبر است؛ زمان واقعی از</span> ‎t = τ R² / D‎ <span dir="rtl">به دست می‌آید.</span>

**<span dir="rtl">۳‏-‏۳‏-‏۳ حل تحلیلی مرجع</span>**

<span dir="rtl">برای</span> ‎D‎ <span dir="rtl">ثابت، معادله (۳‏-‏۶) حل تحلیلی دارد (</span>‎Crank‎ <span dir="rtl">\[</span>‎۱‎<span dir="rtl">\]) که در این پایان‌نامه مرجع صحت‌سنجی حل عددی است:</span>

|                                                                                                           |                                         |
|-----------------------------------------------------------------------------------------------------------|-----------------------------------------|
| $F(\tau)\  = \ 1\  - \ \frac{6}{\pi^{2}}\sum_{n = 1}^{\infty}{\frac{1}{n^{2}}\ exp( - n^{2}\pi^{2}\tau)}$ | **<span dir="rtl">معادله (۳‏-‏۷)</span>** |

<span dir="rtl">سری تا جایی جمع زده می‌شود که کران باقی‌مانده آن از</span> ‎۱۰<sup>-۱۳‎</sup> <span dir="rtl">کمتر شود. از این حل، زمان بی‌بعد نیمه‌رهایش</span> ‎τ۵۰ = ۰٫۰۳۰۵۵‎ <span dir="rtl">به دست می‌آید. زمان مشخصه نفوذ</span>[^6] <span dir="rtl">نیز چنین تعریف می‌شود:</span>

|                                           |                                         |
|-------------------------------------------|-----------------------------------------|
| $\tau_{D}\  = \ \frac{R^{2}}{\pi^{2}\ D}$ | **<span dir="rtl">معادله (۳‏-‏۸)</span>** |

**<span dir="rtl">۳‏-‏۴ تولید هندسه</span>**

<span dir="rtl">هندسه فیزیکی یک کره به شعاع</span> ‎R‎ <span dir="rtl">است (شکل ۳‏-‏۱ الف). چون شرط اولیه، شرط مرزی و خواص ماده به زاویه بستگی ندارند، مسئله سه‌بعدی دقیقاً به یک مسئله یک‌بعدی روی پاره‌خط</span> ‎۰‎ <span dir="rtl">≤</span> ‎r‎ <span dir="rtl">≤</span> ‎R‎ <span dir="rtl">کاهش می‌یابد. این کاهش تقریب نیست؛ جمله</span> ‎۱/r²‎ <span dir="rtl">در معادله (۳‏-‏۱) اثر هندسه کروی را کامل نگه می‌دارد. در نرم‌افزارهای اجزای محدود همین مسئله به شکل نیم‌دایره متقارن محوری دوبعدی ساخته می‌شود که با دوران حول محور تقارن کره را می‌سازد؛ نتیجه هر دو یکی است و هندسه یک‌بعدی هزینه محاسباتی بسیار کمتری دارد.</span>

**<span dir="rtl">مدل پایه با ضریب نفوذ مستقل، تخلیه ذره را در کمتر از یک ثانیه پیش‌بینی می‌کند، در حالی که رهایش واقعی</span> ‎۵‎ <span dir="rtl">تا</span> ‎۲۳‎ <span dir="rtl">روز تا نیمه طول می‌کشد؛ اختلاف هفت تا هشت مرتبه بزرگی است. این اختلاف از حل عددی نیست (بخش‌های ۳‏-‏۷ تا ۳‏-‏۹ خطای عددی را زیر</span> ‎۰٫۱‎ <span dir="rtl">درصد نشان دادند) و با تغییر</span> ‎φ‎ <span dir="rtl">در بازه معقول هم جبران نمی‌شود. پس نفوذ داروی آزاد به‌تنهایی سازوکار کنترل‌کننده نیست و مدل باید سازوکارهایی را که دارو را در شبکه نگه می‌دارند در بر بگیرد. این نتیجه، دلیل روش‌شناختی بخش بعد است.</span>**

**<span dir="rtl">۳‏-‏۱۲ مدل توسعه‌یافته: نفوذ، اتصال و تخریب</span>**

<span dir="rtl">در مدل توسعه‌یافته دارو در سه حالت در نظر گرفته می‌شود: داروی آزاد</span> ‎C‎ <span dir="rtl">که نفوذ می‌کند، داروی متصل برگشت‌پذیر</span> ‎S‎ <span dir="rtl">که روی گروه‌های باردار ژلاتین نشسته است و داروی محبوس</span> ‎P‎ <span dir="rtl">که فقط با تخریب شبکه آزاد می‌شود (کمپلکس پلی‌یونی یا گیرافتاده در شبکه) \[</span>‎۱۲‎<span dir="rtl">،</span> ‎۱۳‎<span dir="rtl">\]. موازنه جرم سه حالت چنین است:</span>

|                                                                                                                                                                                                                    |                                          |
|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------|
| $\frac{\partial C}{\partial t}\  = \ \frac{1}{r^{2}}\frac{\partial}{\partial r}\left( D\ r^{2}\frac{\partial C}{\partial r} \right)\  - \ k_{on}\ C\ (S_{\max}\  - \ S)\  + \ k_{off}\ S\  + \ r_{d}\ (S\  + \ P)$ | **<span dir="rtl">معادله (۳‏-‏۱۶)</span>** |

|                                                                                                     |                                          |
|-----------------------------------------------------------------------------------------------------|------------------------------------------|
| $\frac{\partial S}{\partial t}\  = \ k_{on}\ C\ (S_{\max}\  - \ S)\  - \ k_{off}\ S\  - \ r_{d}\ S$ | **<span dir="rtl">معادله (۳‏-‏۱۷)</span>** |

|                                                                                                            |                                          |
|------------------------------------------------------------------------------------------------------------|------------------------------------------|
| $\frac{\partial P}{\partial t}\  = \  - \ r_{d}\ P,\ \ \ \ \ r_{d}(t)\  = \  - \ \frac{1}{g}\frac{dg}{dt}$ | **<span dir="rtl">معادله (۳‏-‏۱۸)</span>** |

‎k<sub>on‎</sub> <span dir="rtl">و</span> ‎k<sub>off‎</sub> <span dir="rtl">ثابت‌های اتصال و جداشدن،</span> ‎S<sub>max‎</sub> <span dir="rtl">ظرفیت جایگاه‌های اتصال و</span> ‎g(t)‎ <span dir="rtl">کسر جرم باقی‌مانده ژل است که از منحنی کاهش وزن اندازه‌گیری‌شده گرفته می‌شود. شرط‌های مرزی</span> ‎C‎ <span dir="rtl">همان معادله‌های (۳‏-‏۳) و (۳‏-‏۴) است و</span> ‎S‎ <span dir="rtl">و</span> ‎P‎ <span dir="rtl">جابه‌جا نمی‌شوند. اثر گلوتارآلدئید در این چارچوب از چهار راه وارد می‌شود: کاهش تورم (افزایش</span> ‎φ‎ <span dir="rtl">و کاهش</span> ‎D‎ <span dir="rtl">در معادله ۳‏-‏۱۵)، مصرف گروه‌های آمین (تغییر</span> ‎S<sub>max‎</sub> <span dir="rtl">و بار شبکه)، کندشدن تخریب (کاهش</span> ‎r<sub>d‎</sub><span dir="rtl">) و تغییر توزیع اولیه دارو میان سه حالت. رابطه‌های کمّی هر یک در فصل بعد از مقاله‌های</span> ‎GA‎ <span dir="rtl">استخراج می‌شود.</span>

<span dir="rtl">استقلال از مش برای این مدل هم جداگانه بررسی شد، چون جمله‌های واکنش مقیاس زمانی تازه‌ای وارد می‌کنند. آزمون روی هندسه</span> ‎GM1‎ <span dir="rtl">با</span> ‎D‎ <span dir="rtl">محاسبه‌شده در</span> ‎φ = ۰٫۱‎ <span dir="rtl">انجام شد. مقدارهای</span> ‎k<sub>on‎</sub><span dir="rtl">،</span> ‎k<sub>off‎</sub><span dir="rtl">،</span> ‎S<sub>max‎</sub> <span dir="rtl">و ثابت تخریب در این آزمون فقط مقدارهای آزمون عددی‌اند (طوری انتخاب شده‌اند که رهایش چند هفته طول بکشد) و ادعای فیزیکی نیستند.</span>

**<span dir="rtl">۳‏-‏۱۳ روش تعیین وزن سازوکارها و پارامترها</span>**

<span dir="rtl">برای اینکه معلوم شود در هر لحظه کدام سازوکار سرعت رهایش را کنترل می‌کند، از مفهوم درجه کنترل سرعت</span>[^22] <span dir="rtl">استفاده می‌شود \[</span>‎۱۴‎<span dir="rtl">\]. سرعت هر سازوکار</span> ‎i‎ <span dir="rtl">با ضریب</span> ‎k<sub>i‎</sub> <span dir="rtl">نشان داده می‌شود (عکس مقیاس زمانی آن: نفوذ، جداشدن، تخریب، تورم). هر ضریب</span> ‎۱۰‎ <span dir="rtl">درصد کم و زیاد می‌شود و اثر آن بر رهایش با تفاضل مرکزی محاسبه می‌شود:</span>

|                                                                                                                              |                                          |
|------------------------------------------------------------------------------------------------------------------------------|------------------------------------------|
| $X_{i}(t)\  = \ |\frac{\partial F(t)}{\partial\ ln\ k_{i}}|,\ \ \ \ \ w_{i}(t)\  = \ \frac{X_{i}(t)}{\sum_{j}^{}{X_{j}(t)}}$ | **<span dir="rtl">معادله (۳‏-‏۱۹)</span>** |

‎w<sub>i‎</sub> <span dir="rtl">وزن بهنجار سازوکار</span> ‎i‎ <span dir="rtl">است و جمع وزن‌ها در هر لحظه یک می‌شود. همین تعریف برای پارامترهای طراحی (نوع و غلظت کراس‌لینکر، نوع ژلاتین، نسبت کراس‌لینکر به ژلاتین، نوع دارو و بارگذاری اولیه) به کار می‌رود: هر پارامتر از راه رابطه‌های فصل بعد به ضریب‌های مدل وصل می‌شود و حساسیت بهنجار</span> ‎t50‎ <span dir="rtl">و رهایش روز اول نسبت به آن گزارش می‌شود.</span>

**<span dir="rtl">۳‏-‏۱۴ معیار مقایسه مدل با داده</span>**

<span dir="rtl">پیش‌بینی مدل در همان زمان‌های نمونه‌برداری آزمایش محاسبه و با سه معیار سنجیده می‌شود: ریشه میانگین مربع خطا (</span>‎RMSE‎<span dir="rtl">، برحسب واحد درصد رهایش)، ضریب تعیین</span> ‎R²‎ <span dir="rtl">و نسبت زمان نیمه‌رهایش پیش‌بینی‌شده به مشاهده‌شده. برای</span> ‎n‎ <span dir="rtl">نقطه داده:</span>

|                                                                                               |                                          |
|-----------------------------------------------------------------------------------------------|------------------------------------------|
| $RMSE\  = \ \sqrt{\frac{1}{n}\sum_{k = 1}^{n}\left( F_{model,k}\  - \ F_{exp,k} \right)^{2}}$ | **<span dir="rtl">معادله (۳‏-‏۲۰)</span>** |

<span dir="rtl">مدل زمانی پذیرفته می‌شود که</span> ‎RMSE‎ <span dir="rtl">آن هم‌اندازه خطای استاندارد آزمایش باشد و روند تغییر با متغیر طراحی (در اینجا بارگذاری دارو) را درست نشان دهد. چون پارامترها برازش نمی‌شوند، خطر بیش‌برازش وجود ندارد و همین داده می‌تواند آزمون مدل باشد؛ برای اعتبارسنجی نهایی، مدل روی داده مقاله‌ای جدا که در ساخت آن به کار نرفته است آزموده می‌شود.</span>

**<span dir="rtl">۳‏-‏۱۵ نرم‌افزار و بازتولیدپذیری</span>**

<span dir="rtl">همه محاسبه‌ها با</span> ‎Python ۳٫۱۳‎ <span dir="rtl">و کتابخانه‌های</span> ‎NumPy ۲٫۵‎ <span dir="rtl">و</span> ‎SciPy ۱٫۱۸‎ <span dir="rtl">انجام شد \[</span>‎۶‎<span dir="rtl">،</span> ‎۱۵‎<span dir="rtl">\]. حل‌گر حجم محدود، حل تحلیلی مرجع، اسکریپت مطالعه مش و فایل داده استخراج‌شده همراه پایان‌نامه نگهداری می‌شوند و با یک فرمان همه جدول‌ها و شکل‌های این فصل را دوباره می‌سازند. زمان اجرای کل مطالعه مش و گام زمانی روی یک هسته پردازنده چند دقیقه است.</span>
