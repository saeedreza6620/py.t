## 1. Built with
- Python 3: numpy, scipy (BDF/LSODA, `minimize_scalar`), matplotlib, pandas. Own spherical finite-volume solver (shells, true volumes/areas), Crank–Nicolson + Rannacher.
- COMSOL-style figures: own matplotlib code (half-disc, jet colormap, white flux arrows) — `comsol_lib.py`, `comsol_fields_lib.py`, `comsol_style.py`.
- Word reports: Node.js `docx` library, OMML equations (`MathFraction`, `MathSubScript`…), then `fix_bidi.py` post-processing; font B Nazanin 12; checked by LibreOffice → PDF render.
- Deck: claude.ai **Slides** artifact type (1920×1080 sections, inline styles, Vazirmatn font). Source generated by `09_deck_source/gen_slides.py`.
- Simulator: one self-contained HTML/JS page (`10_simulator_source/index.html`) published as artifact.
- Notebooks: Colab-ready `.ipynb` in `08_stepD/` and `01_stage1-4_mdl/colab/`.

## 3. How to change things
- **Change a parameter / data point** → edit the data dict `F` in `03_degradation_doe_kodra/kodra_doe.py` (Kodra) or `abd06_sync.py` (Abdekhodaie), re-run, then re-run the report and deck builders. The simulator has its own copy of the numbers in `index.html` — update it too and check against the Python JSON.
- **Add a step to the ladder** → add a branch in `model(c, step, t)` in `kodra_doe.py`; label it honestly (rejected / partial / valid prediction / descriptive).
- **Change report text** → `02_abdekhodaie2006/report/build_report.js` (helpers in `lib_rtl.js`: `P, H1, H2, BUL, NOTE, KEY, table, img, EQ`). Equations: use `EQ(...)` (OMML). Never put formulas as plain text (they scramble in RTL).
- **Change figure numbering** → figures are referenced by number in the report; paper figure references (Fig. 12, 13) must not be renumbered.
- **Change slides** → edit `gen_slides.py`, regenerate, republish. Style: navy #0E1B4D, blue #2F5CF0, orange #EB6834, green #1BAF7A.
- **Add a new paper** → one dataset per formulation; take every parameter from the same formulation; no fitted D; no invented swelling.

## 4. Lessons already learned (do not repeat)
- Word Heading styles → collapse arrows: use plain styled paragraphs. In a bidi paragraph use `AlignmentType.LEFT` to appear on the right.
- LSODA with `koff=0` gave NaN: use analytic `1-exp(-t/τ_D)` for steps ≤ 2.
- Two files named `comsol_lib.py` clash: part B's is `comsol_fields_lib.py`.
- Artifact publish is refused unless the artifact was read in the session; `edits` cannot be combined with `files`.
- Don't call the match with Abdekhodaie "synced": say "got close, not fully" and give the two reasons.
