# BeautyWallet v6 — Mobile Exact Luxe

این نسخه یک وب‌اپ موبایل واقعی و تعاملی است که بر اساس طراحی مرجع سرمه‌ای–طلایی ساخته شده، نه یک تصویر ثابت.

## پوزیشن محصول
BeautyWallet = کیف شخصی مراقبت پوست

- ورودی: «این رو بخرم؟»
- هسته: حافظه روتین، خرید، بودجه و تصمیم‌ها
- بازگشت: ثبت نتیجه مصرف و عکس اختیاری
- اصل اعتماد: فروشگاه نیستیم؛ تصمیم قبل از خرید صادر می‌شود.

## اجرا
ساده‌ترین روش:

```bash
python -m http.server 8000
```

سپس مرورگر موبایل را روی `http://localhost:8000` باز کنید.

## داده
کاتالوگ فعلی از دیتاست نسخه قبلی پروژه وارد شده و در فایل `products.js` است. اطلاعات پروفایل، کیف، تصمیم‌ها و نتیجه‌ها با localStorage روی همان دستگاه ذخیره می‌شود.
