# صنعت‌هاب (SanatHub) — نسخه اول

بازار تجمیعی ضایعات مس و برنج کارگاه‌های تراشکاری. هر کارگاه بار خودش را اعلام می‌کند. وقتی **۱۰ کارگاه** یک منطقه (یا **۳ تن** بار) جمع شدند، یک «مگا-بار» آماده فروش می‌شود. خریدار عمده (ریخته‌گری) آن را با قیمت همان لحظه می‌خرد و با یک مسیر بهینه از همه برمی‌دارد. هر کارگاه به قیمت عمده‌بار پول می‌گیرد.

## چه چیزهایی کار می‌کند

| بخش | امکانات |
| --- | --- |
| **تابلوی قیمت زنده** | دلار آزاد (نوسان یا هر API) × مس جهانی، یا قیمت کاتد بورس کالا. هر ۳۰ ثانیه به‌روز می‌شود و تغییرها چشمک می‌زنند. قیمت هر گرید = کاتد × ضریب. کنار قیمت عمده، «خرده‌بار دلال» و «سود تجمیع در هر تن» هم نشان داده می‌شود. |
| **تراشکار** | ورود با کد پیامکی، ثبت کارگاه با موقعیت GPS و شبا، اعلام بار (گرید، وزن، روغن)، برآورد زنده مبلغ، و نمایش جایگاهش در مگا-بار (شمش‌ها). لغو تا قبل از فروش. |
| **تجمیع** | برای هر «منطقه + گرید» یک مگا-بار باز است. با رسیدن به حد نصاب کارگاه یا وزن، خودکار «آماده فروش» می‌شود. اگر کسی لغو کند، به حالت تجمیع برمی‌گردد. |
| **خریدار** | بازار مگا-بارهای آماده با ارزش تخمینی و طول مسیر. دکمه «خرید» قیمت و دلار همان لحظه را برای کل بار قفل می‌کند (اگر دو خریدار هم‌زمان بزنند، فقط یکی موفق می‌شود). |
| **مسیر و توزین** | مسیر بهینه (نزدیک‌ترین همسایه + 2-opt) روی نقشه، تماس و مسیریابی هر کارگاه، ثبت وزن باسکول، روغن واقعی و کد مغایرت. «رد بار» با مغایرتِ تخلف برای کارگاه تخلف و جریمه ثبت می‌کند. سه تخلف یعنی محدودیت اعلام بار. |
| **تسویه** | برگه تسویه قابل چاپ: مبلغ هر کارگاه با شبا، جمع واریز، و کارمزد صنعت‌هاب (از خریدار). **پلتفرم پول نگه نمی‌دارد.** خریدار مستقیم به شبای کارگاه واریز می‌کند (مطابق محدودیت شاپرک برای نگهداری وجه). |
| **مدیر** | حالت قیمت (دلاری یا بورس کالا)، دلار پشتیبان، مس جهانی، پریمیوم، ضرایب گرید، کسر روغن، حد نصاب‌ها، کارمزد و جریمه. تأیید خریدارها، مسدودسازی، آماده‌کردن یا لغو دستی مگا-بار. |

## اجرای محلی

```bash
cd sanathub
npm install
npm run seed:demo          # ۱۱ کارگاه نمونه در شمس‌آباد + ۱ خریدار تأییدشده
npm run dev                # http://localhost:3000
```

در حالت توسعه، کد ورود روی صفحه نشان داده می‌شود. شماره‌های نمونه:

- تراشکارها: `09120001001` تا `09120001011`
- خریدار: `09121110000`
- مدیر: هر شماره‌ای که در `ADMIN_PHONES` باشد

## راه‌اندازی روی لیارا (یک بار)

1. در لیارا یک برنامه جدید با پلتفرم **Next.js** بسازید، مثلاً به اسم `sanathub`.
2. یک **دیسک** (مثلاً ۱ گیگ) بسازید و به `/usr/src/app/data` وصل کنید. **بدون دیسک، با هر دیپلوی دیتابیس پاک می‌شود.**
3. در «متغیرهای محیطی» لیارا این‌ها را بگذارید:
   - `SESSION_SECRET` (رشته تصادفی بلند)
   - `ADMIN_PHONES`
   - `DATA_DIR=/usr/src/app/data`
   - کلیدهای کاوه‌نگار (`KAVENEGAR_API_KEY` و `KAVENEGAR_TEMPLATE`)؛ تا وقتی تنظیم نشده‌اند، `OTP_DEV_SHOW=1`
   - کلید نوسان (`NAVASAN_API_KEY`) برای دلار زنده

   فهرست کامل در `.env.example` است.
4. در گیت‌هاب، در Settings ← Secrets and variables ← Actions ← **Variables**، متغیر `SANATHUB_APP_NAME` را برابر نام برنامه لیارا بگذارید. Secret `LIARA_API_TOKEN` از قبل برای بیوتی‌ولت وجود دارد.
5. از این به بعد هر push روی شاخه `sanathub` که پوشه `sanathub/` را تغییر دهد، این کارها را انجام می‌دهد: build، تست دود (seed + بالا آمدن سرور + چند صفحه)، و دیپلوی.

## منطق قیمت (در `src/lib/prices.ts`)

```
کاتد (تومان/کیلو) = مس جهانی (دلار/تن) ÷ ۱۰۰۰ × دلار آزاد × (۱ + پریمیوم)   ← حالت دلاری
                   = آخرین قیمت کاتد بورس کالا                                ← حالت بورس
قیمت عمده گرید   = کاتد × ضریب گرید
پرداختی کارگاه   = وزن باسکول × (۱ − کسر روغن) × قیمت قفل‌شده لحظه خرید
کارمزد           = درصد کارمزد × جمع پرداختی (از خریدار)
```

ضرایب پیش‌فرض از میانگین قیمت عمده‌بار ایران‌ضایعات و کاتد بورس کالا در آبان ۱۴۰۵ کالیبره شده‌اند. همه از پنل مدیر قابل تغییرند و باید با اولین معامله‌های واقعی و آنالیز اسپکترومتر خریدار دوباره کالیبره شوند.

## ساختار کد

```
src/db/schema.ts         جدول‌ها (کاربر، کارگاه، خریدار، گرید، مگا-بار، بار، تنظیمات، تاریخچه قیمت، OTP)
src/lib/prices.ts        موتور قیمت + فید زنده دلار/مس + تاریخچه
src/lib/batching.ts      اعلام بار، تجمیع، حد نصاب، خرید اتمیک، ثبت توزین، تسویه
src/lib/route.ts         مسیر بهینه جمع‌آوری
src/lib/auth.ts          ورود پیامکی و نشست
src/app/actions.ts       همه عملیات فرم‌ها (Server Actions)
src/app/(workshop|buyer|admin|prices|login|onboarding)
scripts/seed-demo.ts     داده نمایشی پایلوت
drizzle/                 مهاجرت دیتابیس (خودکار در اولین درخواست اجرا می‌شود)
```

## گام‌های بعدی پیشنهادی

- آپلود عکس بار و عکس مغایرت (فعلاً عکس‌ها در گروه پایلوت ارسال می‌شوند)
- اتصال به اپلیکیشن نشان برای نقشه واقعی و زمان سفر
- اعلان پیامکی «مگا-بار شما آماده/فروخته شد» به کارگاه‌ها
- دفتر خرید و فروش دیجیتال قابل ارائه به اتحادیه و پلیس اماکن
- ربات بله برای اعلام بار بدون باز کردن سایت
