## یک واقعیت مهم: Grok چه کاری می‌تواند بکند و چه کاری نه

| کار | Grok در چت معمولی (grok.com یا اپ) | ابزار برنامه‌نویسی با دسترسی به ترمینال و گیت |
| --- | --- | --- |
| فکر کردن، استراتژی، مارکتینگ، متن ریلز و پیامک، تحلیل عددها | ✅ عالی | ✅ |
| خواندن کد و پیشنهاد تغییر | ✅ (اگر فایل‌ها را بارگذاری کنی) | ✅ |
| اجرای تست‌ها، ساختن، push به گیت‌هاب، انتشار روی لیارا | ❌ | ✅ |
| دیدن مخزن خصوصی گیت‌هاب | ❌ مگر خودت فایل بدهی | ✅ با دسترسی تو |

یعنی برای **استراتژی و مارکتینگ**، Grok با همین zip کامل کار می‌کند. برای **تغییر کد**، Grok کد را می‌نویسد و یکی از این دو راه لازم است:
1. **یک ابزار برنامه‌نویسی با دسترسی به مخزن،** که خودش تست کند و push کند. اگر از Grok داخل چنین ابزاری استفاده می‌کنی، همان کار می‌کند.
2. **خودت فایل را عوض کنی** و دستورهای بخش «تغییر کد» پایین را اجرا کنی.

**هرگز** رمز گیت‌هاب، توکن لیارا، `ADMIN_TOKEN` یا هیچ کلیدی را به Grok یا هیچ چت دیگری نده. این قانون پروژه است.

## راه‌اندازی در Grok (۵ دقیقه)

1. یک گفت‌وگوی تازه در Grok باز کن. اگر «پروژه» یا «Workspace» دارد، یکی به اسم «بیوتی‌ولت» بساز تا فایل‌ها بمانند.
2. فایل **`ALL_IN_ONE.md`** را بارگذاری کن.
3. متن **`01_GROK_PROMPT.txt`** را کپی کن، آخرش کار امروزت را بنویس و بفرست.
4. اولین جواب Grok باید **فارسی** باشد و قانون‌ها را درست خلاصه کند. اگر نکرد، بگو «اول بخش ۳ فایل تحویل را دوباره بخوان».
5. برای کار روی یک فایل کد، همان فایل را از پوشه‌ی `source/` بارگذاری کن.

## نقشه‌ی سریع پروژه

**محصول:**
- اپ فارسی مراقبت پوست که قبل از خرید، محصول را با پوست و روتین کاربر می‌سنجد.
- **جایگاه:** «بیوتی‌ولت طرف خریداره. ما چیزی نمی‌فروشیم؛ می‌گیم چی نخری.»
- **نقطه‌ی ورود:** «پوستم به هم ریخته».
- **دلیل ماندن:** صفحه‌ی «امروز» و یادآورها.

**فنی:**

| پوشه | چیست |
| --- | --- |
| `source/lite/` | سرور واقعی (Node 22) روی لیارا |
| `source/claude/` | لایه‌های اپ |
| `source/android-app/` | اپ اندروید (Capacitor) |
| `source/.github/workflows/` | انتشار، ساخت APK، داده‌ی هفتگی |

**درآمد:**
- الماس، فقط بعد از دیدن ارزش.
- دستیار: ۸ پیام هدیه، بعد ۱ 💎 = ۱۰ پیام.
- نتیجه‌ی کامل تست ساعد: ۳ 💎.
- پرداخت کارت‌به‌کارت با ۴ رقم آخر کارت.

**مارکتینگ:**
- **پیام اصلی:** «زدی و پوستت داغون شد؟ اول آرومش می‌کنیم، بعد با هم پیدا می‌کنیم کدوم بوده.»
- **بسته‌ی محتوای ۱** آماده است: ۴ ریلز، پست پین‌شده، دایرکت، جواب انجمن، برنامه‌ی ۱۴ روزه.
- **حلقه‌ی داده‌ی هفتگی:**
  1. جمعه: عددهای اینستاگرام در `/admin/marketing`
  2. جمعه شب: GitHub داده را برمی‌دارد
  3. شنبه: هوش مصنوعی بسته‌ی بعدی را می‌نویسد

## کارهای آماده برای Grok (مثال)

**مارکتینگ** (بدون نیاز به کد):
- «با داده‌ی این هفته (عددهای `/admin/marketing` را می‌چسبانم)، طبق اسکیل `beautywallet-weekly` بسته‌ی محتوای ۲ را بنویس.»
- «۵ مصاحبه‌ی سوییچ را که یادداشت کرده‌ام تحلیل کن و بخش زبان مشتری را به‌روز کن.»
- «متن پیام عضو بنیان‌گذار برای ۵ کاربر فعال را بنویس.»
- «صفحه‌ی کافه‌بازار را برای ASO بهتر کن.»

**محصول و استراتژی:**
- «تست دستی پرایوت با ۱۰ عضو را قدم‌به‌قدم بچین.»
- «برای چهار سؤال بی‌جواب بخش ۱۱، گزینه‌ها و پیشنهادت را بگو تا تصمیم بگیرم.»

**فنی** (کد را Grok می‌نویسد؛ اجرا با ابزار برنامه‌نویسی یا خودت):
- «پیگیری روز ۳۰ برنامه‌ی آرام‌سازی ("دوباره تکرار شد؟") را به `claude/calm.js` اضافه کن، با رعایت قانون حفظ داده.»
- «دکمه‌ی "به دوستت بگو" با هدیه‌ی دوطرفه را طراحی کن.»

## اگر خودت می‌خواهی تغییر کد را اعمال کنی

```bash
git clone https://github.com/saeedreza6620/py.t && cd py.t      # needs your GitHub login (private repo)
# put Grok's changed files in place, then:
node scripts/apply-sweet-ui.mjs 146 && node scripts/build-lite.mjs   # a NEW version number every time
npm i --no-save typescript@5.9.3
for t in skin-fit catalog-review catalog-routine bank explain catalog-quality keep-user-data; do node scripts/test-$t.mjs || echo "FAIL $t"; done
git add -A && git commit -m "v146: …" && git push origin main        # GitHub deploys to Liara automatically
```

**اگر یکی از ۷ تست شکست خورد، push نکن.** خروجی خطا را به Grok بده تا درستش کند.
