## حلقه‌ی داده (از ۲۱ آبان ۱۴۰۵)

1. تیم هر جمعه عددهای اینستاگرام را در پنل `/admin/marketing` وارد می‌کند.
2. جمعه شب، GitHub خلاصه‌ی هفته را از `/admin/marketing.json` برمی‌دارد و در `data/marketing/` ذخیره می‌کند. این خلاصه فقط عدد کلی دارد، نه اسم یا شماره.
3. هوش مصنوعی با اسکیل `.claude/skills/beautywallet-weekly/` بیشترین افت قیف را پیدا می‌کند و بسته‌ی محتوای بعدی را می‌نویسد.

## چیزهایی که عمداً اینجا نیست

- **شماره موبایل و اسم کاربران.** فهرست زنده در پنل `/admin` است. داده‌ی شخصی کاربر نباید در تاریخچه‌ی گیت بماند، حتی در مخزن خصوصی، چون پاک کردنش از تاریخچه سخت است.
- **کلیدها، رمزها، شماره کارت.** فقط در لیارا، GitHub Secrets یا پنل ادمین هستند.
- **سهام و قرارداد هم‌بنیان‌گذار.** این‌ها سند حقوقی تیم‌اند و در گفت‌وگوهای فنی جمع‌بندی نشده‌اند. اگر صاحب پروژه بخواهد، جدا اضافه شوند.
